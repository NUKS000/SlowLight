# Contributing to SlowLight

Thanks for taking an interest in SlowLight.

The project is intentionally small. Contributions should preserve that simplicity rather than expand the app for its own sake.

## Current state

The public Android source is being prepared for release.

Until it is published, issues are welcome for:

- usability ideas
- accessibility considerations
- documentation improvements
- Android-device compatibility observations
- simple product suggestions

## Before contributing

Please keep these principles in mind:

- preserve offline-first behaviour;
- avoid adding accounts or cloud dependencies without a strong reason;
- avoid unnecessary analytics or tracking;
- keep the core breathing session visually quiet;
- do not introduce medical or treatment claims;
- prefer small, understandable changes.

## Pull requests

Once source is available:

1. Fork the repository.
2. Create a focused branch.
3. Keep the change small where possible.
4. Explain the problem being solved.
5. Include testing notes.
6. Open a pull request.

A pull request should answer:

- What changed?
- Why is it useful?
- How was it tested?
- Does it change user data, permissions, networking or privacy behaviour?

## Code style

Project-specific build, formatting and test instructions will be added when the Android source is published.

## Issues

For normal bugs or ideas, use the GitHub issue templates.

For security concerns, follow [SECURITY.md](SECURITY.md).
