# Security Policy

## Supported versions

SlowLight is currently a working prototype and has not yet published a formal stable release.

Security support will begin with the first public source release.

## Reporting a vulnerability

Please do **not** publish sensitive security details in a public issue.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository.

If private reporting is not available, contact the repository owner through their GitHub profile and provide only enough public information to establish contact.

## Privacy direction

SlowLight is designed to minimise its security and privacy surface:

- no account required;
- no cloud dependency for the core experience;
- no advertising;
- no analytics in the current prototype concept;
- no unnecessary personal-data collection.

Any future change that adds networking, remote services, analytics, sensitive permissions or user-data storage should be treated as a security- and privacy-relevant change.
