# Project Notes

## Product definition

SlowLight is an offline visual breathing pacer for Android.

The prototype uses an expanding/contracting full-screen visual cue and gradually moves from approximately 11 breaths per minute toward 6 breaths per minute.

## Current known prototype features

- 8-minute session
- 20-minute session
- progressive pacing
- brightness control
- pause
- resume
- stop
- offline operation

## Proven state

The prototype has been installed and used on a Samsung Galaxy S24 Ultra.
